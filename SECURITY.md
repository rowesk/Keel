# Security reports

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/rowesk/Keel/security/advisories/new). Do not disclose the exploit or affected private URLs in a public issue.

Include the affected Keel version, macOS version, impact, and a minimal reproduction using fictional data. Do not send passwords, cookies, signing keys, or your browser profile.

Keel is an early project maintained by Chris Rowe. Security fixes target the latest released version; older versions do not have a separate support branch. There is no guaranteed response time or bug bounty.
